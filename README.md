# Student Grade Tracker

## About the Project
Student Grade Tracker is a simple Java application used to manage student marks and calculate academic performance.

## Features
- Enter student details
- Enter marks for subjects
- Calculate total marks
- Calculate percentage
- Display grades

## Technologies Used
- Java
- VS Code

## How to Run
1. Download the project from GitHub.
2. Open the project in VS Code.
3. Open the Java source file.
4. Compile and run the program.

## Purpose
The purpose of this project is to make student mark calculation easier and faster.
